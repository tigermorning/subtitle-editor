# 문서 안 이미지 127장 — 판정 기록

`.docx` 세 파일에 이미지가 127장 들어 있다(작업 기본 원칙 48, 표기_맞춤법_번역 64,
SubtitleEdit 15). 표와 예시가 이미지로 들어가 있어 텍스트 추출로는 보이지 않는다.

문단 순서와 이미지 관계를 맞춰(`r:embed` → `document.xml.rels`) 어느 자리의 이미지인지
매핑하고, 규칙이 든 것부터 읽어 반영했다. 추출 목록은 세션 스크래치패드에 있고,
같은 방법으로 언제든 다시 뽑을 수 있다.

## 교정기로 넘길 것 (표기_맞춤법_번역 나머지 62장)

편집기가 아니라 **한국어 교정기**가 다룰 내용이다. 자막 문법과 무관한 한국어 규범이라
이 저장소에 검사로 넣지 않는다. 교정기 작업 때 이 목록을 보고 하나씩 확인한다.

| 이미지 | 주제 |
|---|---|
| NOTA-001~003 | 띄어쓰기 판별 단계(품사 기준) |
| NOTA-004~006 | 의존명사 목록 / 변경된 용어(차별적 언어) / 순화어 |
| NOTA-007~009 | 단위성 명사·숫자 표기(세 자리 쉼표, 네 자리 띄어쓰기) |
| NOTA-010~012 | 합성어 예시 / 구어체 / 번역투 |
| NOTA-014·016~021 | 문장부호(단위 조합 문자·중간 이름 온점·말줄임표·물결표·쌍점·`&`·전각/반각) |
| NOTA-022~041 | 외래어 표기법 (IPA 대조표, 일본어·중국어·이탈리아어·태국어 한글라이즈, 표기 세칙) |
| NOTA-042~050 | 고유명사 띄어쓰기(음식·지명·품종·인명·상표명) |
| NOTA-051~053 | 단위(톤·인구밀도·신장·대소문자 구별·기억장치) |
| NOTA-054~062 | 맞춤법(명사/접사, 부딪치다/부딪히다, 종결어미, `-ㄹ걸`, 뿐·맨·한번, 잘/못, 보조 용언) |
| NOTA-063~064 | 분야별 용어(건축·의료) / 한국인의 말습관 |

이 중 **NOTA-014·016~021(문장부호)과 NOTA-051~053(단위)**은 자막에도 걸리므로,
교정기에 들어가면 편집기가 그 결과를 그대로 받는다(`--korean` 레인).

## 읽지 않은 것 (SubtitleEdit 15장)

SE 화면 설명(메뉴 위치·옵션 창·파형 조작)이다. 규칙이 아니라 조작법이고, 우리 도구는
SE를 조작하지 않으므로 반영할 것이 없다. 사용자 교육 자료로서의 값은 그대로 있다.

## 방법 기록

같은 방법으로 다시 뽑는 절차:

1. `word/document.xml`을 문단(`</w:p>`)으로 쪼개며 텍스트와 `r:embed`를 순서대로 수집
2. `word/_rels/document.xml.rels`로 `r:embed` → `media/imageN.jpg` 매핑
3. 이미지 앞뒤 문단 텍스트를 문맥으로 붙여 목록화 → 어느 표인지 알고 골라 읽는다

이미지 안 표를 사람이 옮겨 적을 필요가 없다.
