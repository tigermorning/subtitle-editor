띄어쓰기 유래
한국어에는 원래 띄어쓰기가 없었음. 구한말 선교사들에 의해 띄어쓰기가 시작됨

띄어쓰기의 기준: 품사
띄어써야 하는 품사: 체언, 용언, 수식언(독립적 단어)

관형사 + 체언(명사/대명사/수사)
부사 + 용언(동사/형용사)

띄어쓸 수 없는 품사: 조사, 접두사, 접미사, 어간, 어미(독립적 단어 x)

🤓 띄어쓰기 판별 단계

어휘
단일어: 품사를 가짐
복합어: 품사를 가짐
합성어(어근+어근) + 파생어(어근+접사)
사전에 하이픈(-)으로 표기 (ex.) 노천-카페, 매듭-짓다, 사랑-하다
무조건 붙여 씀
(vs.) 명사구: 품사가 없음 단어가 아닌 구(말뭉치)
사전에 ‘^’로 표기 (ex.) 예방^접종
띄어쓰기 원칙, 붙임 허용

고유명사 vs. 전문용어
고유명사는 다 띄는 게 원칙, 의미 단위별로 붙임 허용
(ex.) 마포 경찰서 강력 팀(원칙) = 마포경찰서 강력팀(허용)

거리 이름의 경우 ‘대로/로/가’는 이름에 붙여 쓰고 ‘길/거리’는 띄어씀이 원칙이지만 고유명사로 간주하여 다 붙임도 허용함

전문용어는 다 띄는 게 원칙, 붙이려면 전부
(ex.) 만성 골수성 백혈병(원칙) = 만성골수성백혈병(허용)

맞춤법 규정 제5-6장 요약
(국립국어원 - 어문 규범 - 한글 맞춤법)
단위성 명사
앞말과 띄어쓰나, 순서/차례를 뜻하거나 아라비아 숫자 뒤에서는 붙임 가능
(ex.) 일층 이층 삼층, 24명

‘제- (접사)’ → 따라서 무조건 붙여야 함
‘차 (의존명사)’ → 따라서 띄어써야 함. 아라비아 숫자가 오거나 차례를 나타내는 경우 붙여 쓸 수 있음 → ‘제1차’와 ‘제일차’도 허용

숫자 뒤에 한글이 오면 띔. 단위는 한국어(킬로미터)보다 영문(km) 선호
(ex.) 3만km (x) 3만 km (o)
무언가를 셀 때 쓰는 의존명사 ‘대’는 숫자와 붙임 가능
(ex.) 꿀밤 열 대, 꿀밤 10대
대립(vs.)을 나타내는 의존명사 ‘대’는 항상 띔. *(예외) 일대일
(ex.) 3 대 1, 피고 대 원고
숫자
아라비아 숫자는 세 자리마다 쉼표, 한글로 쓸 때에는 네 자리마다 띄어씀
(ex.) 일억 이천삼백사십오만 육천칠백팔십구, 1억 2,345만 6,789

국어사전

북한어, 방언 쓰면 안 됨
가득-차다 (형용사)(방언) ‘가득하다’의 전남 방언
(vs.) 표준어는 ‘가득 차다’로 띄어쓰기

참고 어휘
같은 글자인데 여러 참고 어휘가 달리는 이유:
품사가 달라 띄어쓰기가 다른 경우
사용 조건이 다른 경우

같은 한자, 다른 한글
(ex.) (모음/ㄴ받침)+-율(率) vs. (ㄴ 받침 뺀 나머지 받침)+-률(率)

표준국어대사전 찾기 실제
‘자세히 찾기’ 활용
(ex.) 갈라파고스 제도의 띄어쓰기가 헷갈리는 경우, ‘자세히 찾기’로 가서 찾는 말의 종류 중 ‘원어’로 설정하고 諸島를 검색하면 쉽게 찾을 수 있음

연산자 활용
?는 글자의 갯수를 의미함 (ex.) ?꾼, ??바람
*는 글자 갯수 관계 없이 다 보여 줌 (ex.) *산맥, 응용*학

3. 이 근거에 따라 ‘조사’이므로 ‘너만큼’을 붙여 씀

3. 의존명사니까 ‘할 만큼’으로 띔

1. 미리 공부할 걸의 띄어쓰기가 궁금한 경우, 사전 ‘자세히 찾기’ 또는 연산자로 검색

인명, 지명 표기 원칙
외국 지명은 현지음을 따름
ex. 모스크바(Moscow), 빈(Vienna), 바르샤바(Warsaw), 라글레이즈(La Gleize)

인명은 국적에 따라, 또 발음이 들리는대로 표기해야 함
ex. 이민 1세대 같은 사람은 원지음으로 하는 게 자연스러움

관용 표현과 현지음이 많이 다를 때는 관용 표현을 따름
ex. 덴 하흐(x) 헤이그(o)

중국 인명, 지명은 1911년 신해혁명을 기준으로 그 이전 시대는 한자어로, 그 이후 시대는 중국어로 표기
ex. 주윤발(x) 저우룬파(o)

일본 인명, 지명은 항상 일본어 발음으로 표기
ex. 이등박문(x) 이토 히루부미(o)

중국, 일본의 지명은 관용 표현과 현지음 모두 허용
ex. 동경/도쿄, 상해/상하이, 대만/타이완

바다는 ‘해’로 통일
ex. 홍해, 발트해, 아라비아해

섬은 ‘섬’으로 통일
ex. 오아후섬, 보라보라섬, 이키섬

지명에 산, 강 등의 뜻이 포함된 채 널리 쓰이면 의미 중복 허용

영어 [p] [t] [k]

[p] [t] [k]가 어말에 있는 경우:
단모음 + [p] [t] [k] → [p] [t] [k]를 받침으로 표기 (ex. 유닛, 셔틀콕)
非단모음 + [p] [t] [k] → [p] [t] [k]에 ‘으’를 붙임 (ex. 플루트, 케이크, 데스크)

[p] [t] [k]가 단어 중간에 있는 경우:
단모음 + [p] [t] [k] + 非 l, r, m, n 자음 → [p] [t] [k]를 받침으로 표기 (ex. 냅킨, 풋볼)
그 외 → [p] [t] [k]에 ‘으’를 붙임 (ex. 디프레션, 비트맵)

영어 [b][d][g]

[b][d][g]는 무조건 ‘으’ 붙임
예외: 로브스터는 2016년부터 랍스터도 허용

영어 [ʃ], [r], and

ex. shrimp 쉬림프(x) 슈림프(o)
