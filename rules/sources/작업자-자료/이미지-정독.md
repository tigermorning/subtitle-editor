# 문서 안 이미지 127장 — 전수 정독 기록 (2026-08-14)

`이미지-판정.md`는 **어느 이미지에 무엇이 있는지 훑어 매핑한 기록**이다. 이 파일은
그다음 단계 — **표 안의 값을 한 칸씩 옮겨 적고, 우리 프로파일과 대조한 기록**이다.

사용자 지시(2026-08-14): "모든 단어·숫자·세부가 중요하다. 이미지 안 수치·표를 정확히
읽어라." 그래서 요약하지 않고 **표를 그대로 옮긴다.**

추출 방법은 `이미지-판정.md` §방법 기록과 같다(`word/document.xml`의 `r:embed` →
`document.xml.rels` → `word/media/`). 파일명은 그 문서의 번호와 같다.

**교정기와 물리는 자리:** 보조용언 띄어쓰기가 넷플릭스·디즈니는 **띄움(원칙)**,
쿠팡은 **규정 없음**이다. 교정기의 `--spacing principle|allowance` 선택이 플랫폼에
따라 정해질 수 있다는 뜻이다. 지금은 사람이 매번 고른다.

**검사로 만들 수 있는데 안 만든 것:** 넷플릭스 "16자 이하는 한 줄" — 한 줄에 들어가는
자막을 두 줄로 나눈 것은 기계가 잴 수 있다.

## WORK-020 — 화자명 (세 플랫폼)

| 화자명 | 넷플릭스 | 디즈니플러스 | 쿠팡플레이 |
|---|---|---|---|
| 스타일 | `[철수]` `[철수/작게]` `[철수/영어]` `[철수/작게/영어]` | `[철수]` `[철수가 작게]` `[철수가 영어로]` | `(철수)` `(철수) [작게]` `(철수) [영어]` |
| 이름 공개 시점 | **주인공·단역 모두** 이름 밝혀지기 전 일반 명칭 → 밝혀진 후 이름 | **주인공은 처음부터 이름 표기** / 단역은 밝혀진 후 | 디즈니와 같음 |
| 넘버링 초기화 | **씬 바뀌면 초기화** | **씬 바뀌면 초기화** | **에피 내에서 번호 유지** |
| 입 확인 시점 = 인점 | **장면전환** | **장면전환** | **대사 시작** |

넷플릭스는 슬래시로 나누고, 디즈니는 서술형(`철수가 작게`), 쿠팡은 소괄호에 어조를
**별도 대괄호**로 뺀다. 프로파일의 `speaker_id_enclosure`가 이 셋을 가른다.

**빠진 것:** 넘버링 초기화 규칙(씬 단위 vs 에피 단위)과 인점 기준(장면전환 vs 대사
시작). 둘 다 스포팅·화자 번호에 걸리는 값인데 프로파일에 없다.

## WORK-022 — 화자명 공통 / 언제 넣나

**공통 (세 플랫폼)**

- **화자명과 대사 첫마디는 반드시 같은 줄에 배치**
- `[남자]`·`[여자]`보다 `[경비]`·`[종업원]` 같은 **직책 표기 선호**
- 철수랑 영희가 동시에 말할 때
  - `[철수와 영희] 출발!` (x)
  - `[철수, 영희] 출발!` (o)
  - `[함께] 출발!` (o)

**언제 넣나 (세 플랫폼 공통)**

- **인점 찍힌 순간 누가 말하는지 불분명할 때** (뒤돌아 있거나, 입이 가려졌거나,
  어둡거나, 사람이 여럿 있거나…)
- **화자명 없이 대사가 시작되어 쭉 이어지는 중 앵글이 다른 데로 넘어갔을 때**
- 예능에서 녹화 영상에 나온 인물과 동일인이 스튜디오에 있을 때 **별개로 취급**

## WORK-024 — 효과음 스타일

| | 넷플릭스 | 디즈니플러스 · 쿠팡플레이 |
|---|---|---|
| 표현 | `[~ 소리]` `[~가 들린다]` **지양** | **의성어 + 상황서술** |
| 형식 | **의성어 + 소리출처**: `[쾅 – 철문]` `[쨍 – 맥줏잔]` `[째깍째깍 – 효과음]` | `[쾅 문 닫는 소리]` `[쨍 건배하는 소리]` |
| 대사 우선 | 효과음보다 **대사로**: `[한숨] 내가 못 살아` (x) / `휴, 내가 못 살아` (o) | 효과음은 **서술형으로**: `[한숨 쉬며] 내가 못 살아` (o) / `휴, 내가 못 살아` (o) |

넷플릭스는 의성어와 출처를 **붙임표(–)로 잇고**, 디즈니·쿠팡은 한 덩어리 서술이다.
넷플릭스만 `[한숨]` 같은 어조 표기를 대사로 바꾸라고 못 박는다.

| 대사와 화면자막이 겹치면 | **화면자막 삭제** | **화면자막 삭제** | **화면자막을 위에 배치해서 병기** (`"식료품 가게"` / `드디어 왔군`) |

**(예능) 번인 화면자막이 대사와 동일하면** (공통)

- **대사 적지 않음**
- 필요할 경우 **화자명만 추가**
- **인점·아웃점은 번인 자막과 같게**

**빠진 것 — 겹침 처리를 `ask`로 두고 있다.** 디즈니·쿠팡 프로파일의 `collision.policy`가
`ask`(작업자가 정함)인데, 이 표는 **넷플릭스·디즈니 = 화면자막 삭제(`dialogue_only`),
쿠팡 = 병기(`keep_both`, 화면자막을 위로)**라고 값을 정해 준다. 자료에 값이 있는데
사람에게 묻고 있었다.

## NOTA-010 — 합성어: 규칙으로 유추하면 틀린다 ⭐

    올라가다 · 담배꽁초 · 가위바위보 · 카우보이모자
    말먹이 · 밝은색 · 중앙난방 · 가솔린차
    봄밤 · 여름밤 · 가을밤 · 겨울밤

**`여름바람`만 취소선이 그어져 있다.** 밤은 사계절 다 붙는데 바람은 여름만 안 된다.
등재 여부에 규칙성이 없다는 뜻이고, **"봄바람이 되니 여름바람도 된다"는 유추가 틀린다**는
증거다. 사전 조회가 유일한 근거여야 하는 이유가 이 한 장에 있다.

## NOTA-011·012 — 말자막(구어체)과 화면자막(문어체)은 정답이 다르다 ⭐

**나이**

| | 말자막(구어체) | 화면자막(문어체) |
|---|---|---|
| | `여덟 살이에요` (o) / `8살이에요` (△) | `상원의원 코리 가드너, 52세` (o) |
| | `서른 살이 되었다` (o) / `30살이 되었다` (o) | `52살` (**x**) |

**수량 표현 어순**

| | 말자막 | 화면자막 |
|---|---|---|
| | `고양이 세 마리를 키우고 있어요` (o) | `다섯 명의 영웅, 그들이 뭉쳤다!` (o) |
| | `세 마리의 고양이를 키우고 있어요` (**x**) | |
| | `와인 두 잔 좀 갖다줄래?` (o) / `두 잔의 와인 좀` (**x**) | |

**같은 표현이 말자막에서는 오류, 화면자막에서는 정답이다.** 교정기가 이것을 가르려면
그 줄이 말자막인지 화면자막인지 알아야 하고, 그 정보는 생성기 쪽(화면자막 표식
`--fn-marker`)에 있다. **두 도구가 물려야 풀리는 자리다.**

## NOTA-025·026 — 국제음성기호와 한글 대조표 (외래어 표기법 별표 1)

자음표(`g n ɲ d ð l r ʁ m b v s θ ʃ ŋ ʒ ʤ z ʣ ʦ ʧ k t p f h x ç`)와
모음·이중모음표를 **모음 앞 / 자음 앞·단어 끝**로 갈라 싣는다.

눈여겨볼 것:

- **`ou` · `oʊ` · `əʊ` → `오`** (자료에 노랑 강조). `스노우`·`보우트`가 아니라 `스노`·`보트`

## NOTA-027 — 이탈리아어 자모와 한글 대조표

## NOTA-028 — 태국어 ⭐ (제4항의 예외)

|---|---|---|
| ph | ㅍ | ㅂ |

| k | **ㄲ** | ㄱ |
| p | **ㅃ** | ㅂ |

## NOTA-030 — 일본어 가나와 한글 대조표

`ka ki ku ke ko` → **어두 `카 키 쿠 케 코` / 어중·어말 `가 기 구 게 고`**,

## 이 저장소(생성기)가 가져갈 것

**말자막과 화면자막의 정답이 다르다** — 이미지(NOTA-011·012)에 이어 본문 CHECK LIST(2)가
같은 것을 다시 못 박는다.

    말자막 나이: -살 (여덟 살, 서른 살)      화면자막 나이: -세 (8세)
    말자막: 영웅 다섯                        화면자막: 다섯 명의 영웅

**단위 표기**: `6-8만 명`(x) → `6만-8만 명`(o). `&` → `및`·`겸`·쉼표.

**법정 계량 단위**(본문 340행대)

- 미터법으로 변환하되 **전문 분야가 비법정 단위를 쓰면 그대로 둔다** — 항공·컨테이너
  `피트`, 미식축구·골프 `야드`, 해양 `해리`·`노트`
- **스크립트가 괄호에 넣어 준 환산값을 믿으면 안 된다**
- `1km`와 `1,000m`는 같은 길이지만 함부로 바꾸면 안 된다. 해발고도는 `m`, 자동차 크기는
  `mm`이고 가로·세로·높이는 `전장/전폭/전고`
- **`ton`은 나라마다 다르다.** 철자가 `tonne`이면 1,000kg이지만 `ton`이면 제작국에 따라
  long ton일 수도 short ton일 수도 있다
- 신장 `5'8"`는 172.72cm다. **`5.8ft`로 계산하면 안 된다**
- 환산값이 `8.0467e+9`로 나오면 8,046,700,000이다
- **단위는 대소문자에 따라 아예 다른 단위가 된다**

**번역 프롬프트가 가져갈 것 — 지양 목록**(본문 780행대, CHECK LIST(3))

    -의 · -것 · -게 되다 · -게 하다 · -말이다 · -는 것 · 이/그/저 · -들 · -시키다
    -수 있다 · "가장 ~한 것 중 하나"
    넣을지 말지 헷갈리면 **빼는 것이 맞다**

- **이중 피동·이중 사동**: 조여지다→조이다, 적응되다→적응하다, 믿겨지다→믿어지다,
  순화시키다→순화하다, 달려오게 하다→부르다
- **사물 주어를 쓰지 않는다.** 행위의 주체는 늘 사람 — "A에서 B로 안전하게 보내 줍니다"(x)
  → "A에서 B로 안전하게 갈 수 있습니다"(o)
- **"가장 ~한 것 중 하나"는 비문**(한국어 최상급은 하나뿐). 최상급을 빼고 "매우 ~한"
- **"문제는/관건은 ~냐/지이다"도 비문**. 질문 형식으로 바꾸거나 "~이 관건이다"
- 부정적 `can`은 `-수 있다`가 아니라 `-할지 모른다`·`-기 십상이다`
- **직접인용은 특별한 경우가 아니면 간접인용으로**
- 우리말식 나열: `A, B, 그리고 C`(x)

**분야별 용어**도 본문에 있다(건축·의료·군대·경찰/사법·게임·마약/성·욕). `--terms`
조사 기능이 채울 자리의 실제 예시들이다. 경찰·사법은 특히 한국에 없는 개념이 많다
(`bar exam` 변호사 시험, `take the plea` 유죄 협상, `statutory rape` 미성년자 의제 강간
— **강간과 다르다**).

## 교정기가 가져갈 것 (외래어 예외 문서에 없는 것)

- **띄어쓰기 판별을 문법으로 먼저 건다** — `뭔 생각 하냐?`는 `뭔`이 관형사라 뒤에 명사가
  와야 하므로 `생각하다`를 가른다. `더 어두운 색`도 `더` 뒤에 부사·용언이 와야 해서 가른다
- **`명사+명사+하다`는 조건을 봐야 한다**: `국어 공부했어`(o) / `특수 제작 했습니다`(o) /
  `초과근무 했다`(o)·`초과 근무 했다`(o) / `통행금지하는`(o) / `상호 협력했다`(o)
- **뜻이 달라지는 붙임**: 집어던지다(그만두다)·뱃속(마음)·집안(가문)·다음날(미래의 어떤
  날)·못쓰다(옳지 않음)·잘살다(부유하다)
- `N+같다`는 `처럼`을 넣어 말이 되면 붙인다. `-율/-률`은 모음·`ㄴ` 받침 뒤에 `-율`
- 보조 용언 붙임 허용의 세부: 단일어+`아/어`, 단일어+`O하다/싶다`, **맨 앞에 한 번만**
  허용, **복합어 뒤는 항상 띔**(단 2음절 복합어는 허용 — `돌봐주다`(o) `돌보아주다`(x)),
  `-어지다`·`-어하다`는 항상 붙임, `-어 v 하다`는 항상 띔(`먹고 싶어 하다`)

## 문장부호 (영상번역)

## 숫자·단위 (업체마다 다를 수 있음)

- **10 이상은 아라비아 숫자**(`18살`), **10 이하는 소리 나는 대로**(`9월`·`네 명`·

- **시간·시각은 무조건 아라비아 숫자**(`9시`)

- 관형사·수사와 함께 쓰면 **한글**(`수천 미터`·`몇 센티미터`). 글자 수 제약이 있으면 영문
- 단위는 우리나라 것으로 바꾸되 **화폐 단위는 그대로**
- **화자의 국적을 따져야 한다** — 미국 화자와 네덜란드 화자가 섞인 다큐에서 "8 정도"
- **가치 평가를 넣지 않는다** — "영하 15도"에 "춥다"를 붙이면 안 된다. 나라에 따라
  그것이 추울 수도 아닐 수도 있다

## 스포팅·장면전환

- 모눈 한 칸 = 0.1초 = 3프레임. **인점은 보이스 시작 전 2~3프레임, 아웃점은 끝난 뒤
  6~9프레임.** 음성이 겹치면 **다음 화자의 인점이 우선**이고, 아웃점 규칙보다
  **최소 듀레이션이 우선**이다
- 장면전환 검출 **민감도 기본 0.2**. 낮을수록 민감하다(팔을 올리는 것도 전환으로 잡는다).
  **애니메이션은 수치를 높인다**
- **자막이 장면전환 앞뒤 0.5초 이내에 걸치지 않게 한다** — 딱 붙이거나 0.5초 이상 벌린다
- 준비 단계: 자막 사이 간격 메우기 500ms(400도 무방), 줄 사이 최소 0ms.
  **영상 맨 처음과 맨 끝까지 채우지 않는다**(몇 프레임이라도 남긴다)
- 화면자막이 페이드인·아웃하면 **나타나기 시작한 지점과 또렷해진 지점의 중간을 인점**,
  **또렷한 지점과 사라지기 시작하는 지점의 중간을 아웃점**으로 잡는다

## 화자명·효과음 (본문 쪽 규칙)

- `(화자명)`과 `[외국어/효과음]`을 나란히 쓰면 **둘 사이를 띄운다**
- 화자 표시와 어조는 **최대한 대사와 같은 줄**. 단 **일반 효과음은 줄바꿈**
- **대사 뒤의 효과음은 넷플릭스에서만 허용, 쿠팡은 절대 불가** — `(윤 목사) 아, 저요? [웃음]`
- 어조에 화자명이 삽입되면 **화자명과 대사 사이에 어조**를 놓는다
- **대사가 규범 표기와 다르면 대사(사투리·일상 언어)를 우선한다.** 단 차이가 크지 않으면
  규범대로
- 자막 제작자 크레딧 길이는 **2초**

## 맞춤법 검사에 대한 자료의 지시 ⭐

- **부산대 맞춤법 검사기에 의존하지 말 것**
- 근거는 **우리말샘·표준국어대사전·우리말365**
- **영한사전의 한국어는 참고하지 않는다**
- **신조어나 은어도 우리말샘에 있으면 쓸 수 있다**

마지막 줄이 교정기 판단과 직접 물린다 — 우리말샘 등재 신조어·은어를 비표준으로 잡으면
자료가 허용하는 것을 위반으로 부르는 것이다.

## 외래어·고유명사 (본문 쪽)

- **지명은 원지음** — `베니스`(x) `베네치아`(o). 통상 붙여 쓴다
- 대체 가능하면 최대한 대체(`샘플`→`표본`). **단 고유명사·전문 용어는 그대로**
  (`운동에너지`를 `운동힘`으로 바꾸지 않는다)
- **작품명은 국내 번역명을 따른다** — `곤 위드 더 윈드`(x) `바람과 함께 사라지다`(o)
- **사명은 회사 공식 표기**를 따른다
- 이름 사이 붙임표는 **제거하고 붙인다** — `Amelia-Rose` 어밀리아로즈,
  `Aaron Wan-Bissaka` 애런 완비사카
- 유럽 언어의 전치사·관사는 뒷말에 붙인다 — `El Cesar` 엘세사르, `Robert De Niro`
  로버트 드니로, `Osteria del sole` 오스테리아 델솔레

## KNP(용어 시트)를 만드는 이유

용어·존대·반말을 통일해 작품의 통일성을 지키고, **협업 시 혼란을 막고**, 감수자를 돕는다.
띄어쓰기가 헷갈리면 전부 용어로 등록한다. **고유명사는 100% 다 적는다.** 특이한 이름은
출처를 비고에 적고, 같은 이름이 여럿이면 구별해 적고, 인물 관계도 적는다.
**별명과 실명은 한국어로 하나로 통일한다**(영어는 별명으로 더 자주 부르지만 한국어
자막에서 실명과 별명을 따로 쓰지 않는다).
